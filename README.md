Программа основана на проекте https://github.com/no-body-in-particular/m5din-makita-xgt но под ардуино, управленлие идет через монитор порта. 
Позволяет 
- произвести разблокировку заблокированного АКБ
- произвести полный сброс, включая количество циклов заряда
- просмотр состояния ячеек, циклов заряда и т.д.
- просмотр статистики использования аккумулятора

Подключение два провода, 
- Батарея - Arduino
- GND - GND
- TR - D2
